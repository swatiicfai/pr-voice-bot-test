## ⚡ The Problem

Writing thorough, structured Pull Request descriptions is one of the most procrastinated tasks in software engineering:
* **10–15 minutes lost** after every code session manually typing documentation and Markdown lists.
* **Flow-state interruption:** Switching mental gears from code to prose breaks developer focus.
* **Poor commit histories:** Developers end up typing hurried, vague descriptions like *"updated auth"* or *"bug fixes"*, making life harder for code reviewers.

---

## 💡 The Solution

**PR Voice Bot** eliminates the keyboard entirely from Pull Request documentation. 

Using **Wispr Flow**, developers simply speak out loud what they built and any breaking changes. The spoken input is instantly captured, processed through an intelligent automation pipeline, and converted into an executive-grade Pull Request description directly on GitHub.

## 🏗️ How It Works (Architecture)

```
  ┌─────────────────────────────────────────────────────────────┐
  │ 🗣️ Speak into Form using Wispr Flow (Ctrl + Win)             │
  │    "Added JWT auth middleware on all protected routes..."   │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ 📋 Tally.so Webhook (Captures Repo URL, PR #, Spoken Notes) │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ ⚙️ Make.com Automation Engine (Instant Webhook Listener)    │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ 🧠 OpenAI GPT-4o-mini (Synthesizes Structured PR Template)  │
  └──────────────────────────────┬──────────────────────────────┘
                                 │
                                 ▼
  ┌─────────────────────────────────────────────────────────────┐
  │ 🐙 GitHub REST API (Automatically Patches PR Body)          │
  └─────────────────────────────────────────────────────────────┘
```

## 📋 The Result: Live Auto-Generated PR

See the actual production output generated by PR Voice Bot on **[Pull Request #1](https://github.com/swatiicfai/pr-voice-bot-test/pull/1)**:

* **🧩 Summary:** High-level executive overview of the changes.
* **🔧 Changes Made:** Clear bulleted list of modifications.
* **💥 Breaking Changes:** Backward-compatibility considerations and status codes.
* **🧪 Testing Checklist:** Concrete test scenarios (e.g. 200 OK vs 401 Unauthorized).

## 🛠️ Tech Stack (100% No-Code)

* **Voice Engine:** [Wispr Flow](https://wisprflow.ai) (Desktop speech-to-text dictation)
* **Form & UI:** [Tally.so](https://tally.so)
* **Automation Orchestrator:** [Make.com](https://make.com)
* **Intelligence:** [OpenAI GPT-4o-mini](https://openai.com)
* **Version Control Integration:** [GitHub REST API](https://docs.github.com/rest) via OAuth
